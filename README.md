# Wordle KMP

Wordle-style word guessing game with several difficulty levels.
Built with Kotlin Multiplatform and Compose Multiplatform (Android target).

## Features

- Word length depends on the selected difficulty
- Letter feedback: correct, present, absent
- Exact original-Wordle handling of repeated letters
- On-screen keyboard that shows the best known state of each letter
- Win/loss dialog with Play Again
- The last selected difficulty is remembered between launches
- History of finished rounds stored locally

## Tech stack

- Kotlin Multiplatform, Compose Multiplatform
- Navigation Compose with type-safe routes (kotlinx-serialization)
- Koin for dependency injection
- DataStore (Preferences) for settings, with an `expect`/`actual` factory
- SQLDelight for round history
- Coroutines, StateFlow
- Unit tests for the reducer and the letter comparison logic

## Architecture

Three layers, dependencies point inward:

- `domain`: game rules and models (`WordComparator`, `GameReducer`, `RoundState`,
  repository interfaces). Pure Kotlin.
- `data`: `DataStoreSettingsRepository`, `SqlDelightHistoryRepository`, the word bank.
- `presentation`: ViewModels, navigation, Compose UI.

Navigation flow: Home -> Difficulty select -> Game(difficulty) -> History.
The selected difficulty is passed as a typed route argument and handed to the
ViewModel through Koin parameters.

## Project structure

    shared/src/commonMain/kotlin/org/example/wordle/
    ├── domain/        # rules, models, repository interfaces
    ├── data/          # DataStore, SQLDelight, word bank
    ├── presentation/  # ViewModels, navigation, UI
    └── di/            # Koin modules

## Run

Open the project in Android Studio and run the `androidApp` configuration,
or build a debug APK:

    ./gradlew :androidApp:assembleDebug

Run unit tests:

    ./gradlew :shared:testAndroidHostTest

## Status
